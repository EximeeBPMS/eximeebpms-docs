**Release date:** 2026-07-01

Open-source release built on top of v1.2.17-ee, consolidating all enterprise edition changes since 1.2.0.

## Added

- Native business events with transactional outbox
- Introduce script security policy with runtime and BPMN parse enforcement
- Make OAuth2 endpoints configurable; respect webapp path
- Multithreaded task handling via `ThreadPoolExecutor`; task execution statistics

## Changed

- Java version and dependencies bump
- Narrow NIO blocking to file and network APIs (script security)
- Replace time-based UUID v1 generation in `StrongUuidGenerator` with random UUID v4
- Bump versions:
  - Groovy: `4.0.22` → `5.0.4`
  - Gson: `2.8.9` → `2.14.0`
  - Jackson: `2.15.2` → `2.21.3`
  - Mockito: `5.10.0` → `5.23.0`
  - Jython: `2.5.3` → `2.7.4`

## Fixed

- Fix task query `OR` for candidate user and candidate group
- Fix Sonar builds
- Jython & BOM fixes; integration test fixes

## Security

- Fix Jython vulnerability
