This tutorial guides you through your first steps of using EximeeBPMS Platform in a plain
[Spring Framework](https://spring.io/projects/spring-framework/) web application, without Spring Boot. If you
are looking for a Spring Boot-based getting started guide instead, see
[Get started with EximeeBPMS and Spring Boot]({{< ref "/spring-boot/_index.md" >}}).

**Target Audience**:
In this tutorial we assume that you are familiar with the basics of Java web application development and the
[Spring Framework](https://spring.io/projects/spring-framework/).
We also assume that you have installed an Eclipse distribution and the Camunda Modeler.
