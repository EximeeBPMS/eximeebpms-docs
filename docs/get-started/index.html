    Get started with EximeeBPMS

    There are different ways to get started with EximeeBPMS Choose from the following guides:
    Quick Start (Java / JS)
    Learn how to model a BPMN 2.0 process using the Camunda Modeler, adding a Java or JavaScript Worker. Deploy it to the EximeeBPMS Platform.
    Spring Boot
    Get started with using EximeeBPMS Platform in Spring Boot application.
    DMN
    Learn how to create a DMN 1.3 decision table using the Camunda Modeler. Package it as a web application and deploy it to an Apache Tomcat Server.
    Spring Framework
    Get started with using EximeeBPMS Platform in a plain Spring Framework application, without Spring Boot.
    Jakarta EE
    Get started developing a process application with JSF, CDI, JPA and EJB, deployed to WildFly.
    Maven Coordinates
    The most commonly used Apache Maven Coordinates for EximeeBPMS.
